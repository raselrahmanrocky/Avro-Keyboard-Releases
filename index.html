Installation

তিন ধাপে শুরু করুন।

একদম সহজ — ডাউনলোড করুন, ইনস্টল করুন, টাইপ করুন।

  1. Step 01

    Release ডাউনলোড করুন

    নিচের ডাউনলোড বাটন থেকে avro-setup.exe বা portable.zip নিন।

    $ curl -O avro-setup.exe
    > downloading latest release
    > ✓ saved
  2. Step 02

    ইনস্টল বা এক্সট্রাক্ট করুন

    Setup চালিয়ে ডিফল্ট সেটিংসে ইনস্টল করুন, অথবা portable zip extract করে যেকোনো ফোল্ডারে রাখুন।

    C:\Program Files\Avro Keyboard\
    ├── avro.exe
    ├── AvroTextConverter.exe
    ├── Qt6Core.dll
    └── resources\
  3. Step 03

    কীবোর্ড সুইচ করুন

    Taskbar-এর Avro icon-এ ক্লিক করে Avro Phonetic সিলেক্ট করুন। Ctrl+Space দিয়ে দ্রুত toggle করুন।

    Shortcut: Ctrl + Space
    > keyboard layout switched
    > ✓ ready to type বাংলা
